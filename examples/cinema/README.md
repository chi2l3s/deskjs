# deskjs cinema example

This app demonstrates file routes, dynamic movie pages, TV focus navigation, Tailwind CSS v4.2, and the theme system.

```bash
pnpm install
pnpm --filter deskjs-cinema-example dev
pnpm --filter deskjs-cinema-example build
```

Set `VITE_API_URL` to load `/movies` from your backend. Without it, local mock data is used.
